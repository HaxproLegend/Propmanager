# PropManager

Front-end-only demo based on submitted PRD v1.2. Built with HTML5, CSS3 and vanilla JavaScript modules; no backend or framework.

## Run in VS Code
Open this folder in VS Code, start the Live Server extension, then open `index.html` with Live Server. IndexedDB needs a local web origin.

## Included demo
Tenant and Property Manager role toggle, maintenance request form, ticket status updates, property directory and sample data. Role persists in localStorage; app data persists in IndexedDB (`propmanager-db`). All records are sample data; role switching is not authentication.
